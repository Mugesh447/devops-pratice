1.pwd



shows the current working directory



2.ls



list of file and directories



3.ls -la



show all file including hidden files with details



4.cd



change the current directory



cd /home/user



5.cd ..



Moves to the parent directory



6.cd \~



Moves into the home directory



7.mkdir



create an the new directory



8.touch



create an the new empty file



Example:

touch file.txt



9.cat

Displays the content of a file

Example:

cat file.txt



10\. cp

copies files or directories



Example:

cp file.txt backup.txt

11.mv

Moves or rename a file.

Example:

mv old.txt backup.txt

12.rm

Removes a file

13.rmdir

Remove an empty directory

eg:

rmdir test



14.clear

clears the terminal screen



15.whoami

shows the current logged-in user



16.date

Displays the current date and time



17.uname-a



Displays the Linux system information



18.df -h

Shows disk space usage



19.free -h

Shows memory/RAM usage



20.ps

shows currently running processes.



21.top

Displays running processes and system resource usage



22.chmod

Change file permission



Example:

chmod +x scipt.sh



23.sudo

Runs a command with administrator previliges.

example:

sudo apt update

24.grep

searches for text inside files

Example:

grep "error" log.txt

25.history

shows previously executed commands
